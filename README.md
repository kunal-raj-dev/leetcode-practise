## 📐 5-Layer Learning Framework

Every problem adheres to a structured 5-layer methodology:

1. **Layer 1: Problem Deconstruction** — Plain-English explanation, input/output analysis, constraint implications, edge case walkthrough.
2. **Layer 2: Concept Building** — Algorithmic intuition, visual mental models, prerequisite theory, C++ STL deep dive.
3. **Layer 3: Problem-Solving Mindset** — Brute force first, inner monologue, guided derivation of optimal approach.
4. **Layer 4: Implementation** — Clean, interview-ready C++ code with Time & Space complexity analysis.
5. **Layer 5: Pattern Extraction** — Reusable patterns, trigger conditions, and curated follow-up problems.
